Mermaid diagrams

domingo, oct 12, 2025

Sintaxis

Azure DevOps

Los diagramas en Azure DevOps se inicializan con tres simbolos de dos puntos (:) seguidos de la palabra mermaid, y termina con tres simbolos de dos puntos.

    :::mermaid
    diagrama
    :::

GitHub

En GitHub los mismos diagramas empiezan por tres simbolos de tilde invertida (`).

    ```mermaid
    diagrama
    ```

Tipos de diagrama

Gráfico de sectores

  pie title Fishermans in countries
    "Norway" : 684
    "Sweeden" : 234
    "Switzerland" : 10

    :::mermaid
    pie title Fishermans in countries
        "Norway" : 684
        "Sweeden" : 234
        "Switzerland" : 10
    :::

Gráfico horizontal

  graph LR;
    A[Hard edge] -->|Link text| B(Round edge) --> C{Decision}
    C -->|One| D[Result one]
    C -->|Two| E[Result two]

    :::mermaid
    graph LR;
