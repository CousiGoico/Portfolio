Git tag

Create

git tag -a {tagName} -m "{message}"; git push origin {tagName}

git tag -a v1.3 -m "My version v1.3"; git push origin v1.3

Delete

git tag -d {tagName}; git push origin --delete {tagName}

git tag -d v1.3; git push origin --delete v1.3
