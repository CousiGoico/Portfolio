Angular

domingo, oct 12, 2025

Requerimientos

  • Node JS

Comandos

  • Instalar Angular CLI npm install -g @angular/cli

  • Ayuda ng –help

  • Version ng version

  • Nuevo proyecto ng new

  • Nuevo componente ng generate componente

  • Nuevo modulo ng genertate module

  • Nueva directiva ng generate directive

  • Nuevo servicio ng generate service

  • Compilar proyecto ng build -c production

  • Servir proyecto ng serve

  • Lanzar test del proyecto ng test
