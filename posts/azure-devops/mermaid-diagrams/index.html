Mermaid diagrams

domingo, oct 12, 2025 | 3 minutos de lectura | Actualizado en domingo, oct 12, 2025

@ Fco. Javier Cousiño

Sintaxis

Azure DevOps

Los diagramas en Azure DevOps se inicializan con tres simbolos de dos puntos (:) seguidos de la palabra mermaid, y termina con tres simbolos de dos puntos.

    :::mermaid
    diagrama
    :::

GitHub

En GitHub los mismos diagramas empiezan por tres simbolos de tilde invertida (`).

    ```mermaid
    diagrama
    ```

Tipos de diagrama

Gráfico de sectores

  pie title Fishermans in countries
    "Norway" : 684
    "Sweeden" : 234
    "Switzerland" : 10

    :::mermaid
    pie title Fishermans in countries
        "Norway" : 684
        "Sweeden" : 234
        "Switzerland" : 10
    :::

    dateFormat YYYY-MM-DD
    excludes 2022-03-16,2022-03-18,2022-03-19
    section Section A

    Task 1          :t1, 2022-03-07, 7d
    Task 2          :after t1 , 5d
    section Section B

    Task 3          :t2, 2022-03-05, 3d
    Task 4          :t3, 2022-03-08, 5d
